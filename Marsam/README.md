# مرسم — المعرض الفني الرقمي

منصة فنية رقمية تعتني بالفن المعاصر وتتيح اكتشاف مواهب الفنانين العرب.

---

## الصفحات

| الملف | الصفحة |
|---|---|
| `Homepage.html` | الرئيسية — المعرض الرئيسي والإحصائيات |
| `explore.html` | الاستكشاف — تصفية الأعمال حسب الأسلوب والمزاج |
| `artwork.html` | تفاصيل العمل الفني |
| `about.html` | نبذة عن المنصة والقيم والقصة |

## الملفات

| الملف | الوظيفة |
|---|---|
| `data.js` | بيانات الأعمال الفنية (ARTWORKS array) |
| `gallery.js` | عرض المعرض الرئيسي في الصفحة الرئيسية |
| `explore.js` | منطق التصفية والبحث في صفحة الاستكشاف |
| `artwork.js` | عرض تفاصيل العمل الفني |
| `style.css` | كل التنسيقات |

## التشغيل

افتح `Homepage.html` مباشرةً في المتصفح — لا يحتاج المشروع إلى سيرفر.

## التقنيات

- HTML5 / CSS3
- JavaScript (Vanilla)
- اتجاه RTL (عربي)

## المعلومات

- **المؤسِّسة:** Zamzam
- **سنة التأسيس:** ٢٠٢٦
- **الأعمال الفنية:** +١٢ عمل
- **الفنانون:** +٦ فنانين
- **الأساليب:** تجريدي، رقمي، انطباعي، بوب آرت، واقعي، مستقبلي
